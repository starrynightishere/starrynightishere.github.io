# Anurag Mishra · Portfolio

A minimal academic and engineering portfolio. Built with semantic HTML, CSS, and a small amount of JavaScript, with no build step or external dependencies.

## Preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Update

Edit `index.html` for content and `assets/css/style.css` for the design. The site works directly on GitHub Pages.
